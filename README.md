
# Insurance Policy Management System

This project was designed using Python as a policy management system for an insurance company. The program enables the addition or suspension of policyholders, the introduction or removal of new products, the processing of payments, and the adjustment of balances accordingly. It is structured using object-oriented programming principles, with separate classes for Policyholder, Product, and Payment, each encapsulated in its own module for modularity and clarity.

## System Requirements

- Python 3.11 or 3.13 (recommended) from: https://www.python.org/downloads/
- VS Code with Pylance extension (recommended)

## Running the Python Script

1. Open VS Code and open the policy_management_system folder
2. Select and run the script: main.py
3. The terminal window would show the account details of two policyholders and the products they paid for.

### Alternatively
1. Open PowerShell and navigate to the directory of the policy_management_system folder
2. Run 'python main.py'
3. The output in the terminal would show the account details of two policyholders and the products they paid for.

## Files Included
- main.py: contains the script to test the classes created in policyholders.py, products.py, and payments.py
- policyholders.py: scripts for creating the class policyholders
- products.py: scripts for creating the class products
- payments.py: scripts for creating the class payments
